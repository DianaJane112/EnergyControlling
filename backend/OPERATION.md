# 第一部分：管理后台操作

> 管理后台通过浏览器访问 `https://mingsifuwu.com` 登录后使用。
> 左侧导航菜单按「电表模式」和「水表模式」切换，功能结构一致，分别管理电表和水表数据。

## 1. 电能/水能管理 — 表计管理

**菜单位置**: 计量管理 → 表计管理（电表模式）/ 水表管理（水表模式）

**路由**: `/meters/physical`（电表）/ `/meters/water`（水表）

### 1.1 数据列表

#### 功能说明

表计管理是平台的核心功能模块，用于管理所有物理电表/水表的信息。列表展示表计的钢印号、表号、商户名、表计类型、状态、在线状态、余额、告警额度、透支额度、付费方式等完整信息。

#### 操作步骤

**查询/重置**
1. 在列表顶部搜索栏输入筛选条件：钢印号、电表号、商户名、客户、状态等（支持 16 个条件组合筛选）
2. 点击「查询」按钮执行筛选
3. 点击「重置」按钮清空所有筛选条件

**数据统计/筛选**
1. 列表顶部展示统计汇总栏，按类型、状态、业务类别、标记状态、通讯状态等维度展示汇总数据
2. 可通过下拉筛选器按状态（启用/停用）、在线状态（在线/离线）快速过滤

**数据展示**
- 列表以分页表格形式展示，支持自定义每页条数
- 列包括：钢印号、表号、商户名、表计类型、状态、余额、告警额、透支额、付费方式 等
- 点击某一行可查看表计详情

#### API 接口

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 统计汇总 | GET | `/api/v1/meters/statistics` | 按类型/状态/在线等多维度汇总 |
| 分页列表 | GET | `/api/v1/meters` | 支持 16 条件组合筛选 |
| 表计详情 | GET | `/api/v1/meters/{id}` | 查看单表详情 |
| 新增表计 | POST | `/api/v1/meters` | 新增电表/水表 |
| 编辑表计 | PUT | `/api/v1/meters/{id}` | 修改表计信息 |
| 删除表计 | DELETE | `/api/v1/meters/{id}` | 逻辑删除 |

### 1.2 设备操作

#### 余额清零
1. 在表计列表中找到目标表计
2. 点击操作列的「余额清零」按钮
3. 确认后该表计关联商户的余额将被清零

### 1.3 批量操作

#### 批量导出
1. 设置好筛选条件（可选，不设则导出全部）
2. 点击「批量导出」按钮
3. 系统生成 Excel 文件并下载

#### 批量修改表计信息
1. 勾选多个表计（通过列表左侧复选框）
2. 点击「批量修改」按钮，弹出编辑面板
3. 选择要修改的字段，输入新值
4. 确认后批量更新所选表计

#### 批量修改电价/水价
1. 勾选多个表计
2. 点击「批量修改电价」（或水价）
3. 输入新的单价
4. 确认后批量更新

#### 批量设置时段
1. 勾选多个表计
2. 点击「批量设置时段」
3. 选择时段模板（尖/峰/平/谷时段定义）
4. 确认后批量应用

#### 设置所有电表时段
1. 点击「设置所有电表时段」
2. 选择时段模板
3. 确认后应用到全部电表

### 1.4 二维码管理

#### 功能说明

表计二维码用于商户通过微信小程序扫码绑定表计。每个表计可生成唯一的二维码，扫码后自动跳转小程序绑定页面。二维码内容格式为 `METER:<type>:<dbNo>`，其中 type=0 表示水表、type=1 表示电表，dbNo 为表计编号。

> **前置条件**: 表计必须有编号（`db_no`）才能生成二维码。若表计缺少编号，系统返回 400 错误「该表计缺少编号（dbNo），无法生成二维码」。此时需先为表计补上编号。

#### 查看二维码信息

1. 在表计列表中找到目标表计
2. 点击「二维码」按钮
3. 系统弹出二维码预览面板，展示：
   - 表计编号（dbNo）
   - 表计名称
   - 表计类型（电表/水表）
   - 关联商户名
   - 二维码内容字符串（如 `METER:1:ELEC000000001`）
4. 管理员可在此确认二维码对应的表计信息无误

#### 下载二维码图片

1. 在二维码预览面板中点击「下载」
2. 系统生成 300×300 PNG 格式二维码图片
3. 浏览器自动下载，文件名格式：`meter_qrcode_<id>.png`
4. 将图片打印后贴到表计外壳上，供商户扫码绑定

#### 批量生成二维码

1. 勾选多个表计（通过列表左侧复选框）
2. 点击「批量导出二维码」
3. 系统按所选表计生成二维码图片包并下载

#### 小程序扫码绑定流程

1. 商户打开微信小程序，点击「扫码绑定」
2. 扫描表计上的二维码
3. 系统解析二维码内容，自动判断：
   - 表计已绑定当前商户 → 直接返回表计详情（幂等）
   - 表计未绑定 → 自动关联到当前商户
   - 表计已绑定其他商户 → 返回错误提示
4. 绑定成功后跳转表计详情页

#### API 接口

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 二维码信息 | GET | `/api/v1/meters/{id}/qrcode` | 获取二维码内容及表计摘要 |
| 二维码图片 | GET | `/api/v1/meters/{id}/qrcode-image` | 下载 300×300 PNG 图片 |

### 1.5 全局操作

#### 全局修改电价/水价
1. 点击「全局修改电价」
2. 输入新的统一单价
3. 确认后更新所有表计的电价/水价

#### 全局修改自动分合闸/开关阀
1. 点击「全局修改自动分合闸」（电表）或「开关阀」（水表）
2. 选择开启或关闭
3. 确认后应用到全部表计

#### 全局设置时段
1. 点击「全局设置时段」
2. 选择时段模板
3. 确认后应用到全部表计

## 2. 电能/水能管理 — 虚拟电表/水表

**菜单位置**: 计量管理 → 虚拟电表（电表模式）/ 虚拟水表（水表模式）

**路由**: `/meters/virtual`（电表）/ `/meters/water-virtual`（水表）

### 2.1 数据列表

#### 功能说明

虚拟电表/水表用于管理总分表拓扑关系。一个总表下可挂载多个子表（虚拟表），用于线损/损耗分析。线损 = 总表最新读数 - 所有分表最新读数之和。

#### 操作步骤

**查询/重置**
1. 支持按项目、总表、子表、类型、状态筛选
2. 支持关键字搜索（匹配总表名/子表名/关系描述）

**数据统计/筛选**
- 列表顶部展示统计汇总，按类型、状态、项目等维度汇总拓扑关系数据

**数据展示**
- 分页表格展示总分表关系，包含总表名、子表名、关系描述、状态等

### 2.2 编辑

#### 选择分组
1. 创建或编辑拓扑关系时，可为子表选择所属分组
2. 从商户分组下拉列表中选择

#### 商户名
1. 创建/编辑拓扑关系时，设置子表的商户名称

#### 告警额
1. 设置子表的告警额度（余额低于此值触发告警）

#### 透支额
1. 设置子表的透支额度（允许透支的最大金额）

#### 付费方式
1. 选择付费方式：预付费（1）或后付费（2）

### 2.3 删除

#### 删除虚拟电表/水表
1. 在拓扑关系列表中找到目标记录
2. 点击「删除」按钮
3. 确认后逻辑删除该拓扑关系

### 2.4 更多操作

#### 充值记录
1. 点击某条拓扑关系的「充值记录」
2. 查看该子表关联的所有充值历史

#### 操作记录
1. 点击「操作记录」查看该拓扑关系的变更历史

#### 二维码
1. 点击「二维码」生成该子表的绑定二维码
2. 商户可通过微信小程序扫码绑定

#### 计费轨迹
1. 点击「计费轨迹」查看该子表的历史计费记录

#### API 接口

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 统计汇总 | GET | `/api/v1/shadow-meter/statistics` | 拓扑关系统计 |
| 分页列表 | GET | `/api/v1/shadow-meter/page` | 筛选查询 |
| 详情 | GET | `/api/v1/shadow-meter/{id}` | 查看详情 |
| 创建关系 | POST | `/api/v1/shadow-meter` | 建立总分表拓扑 |
| 更新关系 | PUT | `/api/v1/shadow-meter/{id}` | 修改拓扑 |
| 删除关系 | DELETE | `/api/v1/shadow-meter/{id}` | 逻辑删除 |

**数据展示**

1. 点击「导出」按钮
2. 系统按当前筛选条件导出基站列表为 Excel

1. 选择一个基站
2. 点击「一键绑定」

1. 选择已绑定的表计，点击「解除绑定」
2. 或点击「解绑所有」批量解绑

## 6. 电能/水能管理 — 分组管理

**菜单位置**: 计量管理 → 分组管理

**路由**: `/operations/group-config`

### 6.1 自定义分组

#### 功能说明

分组管理允许管理员创建自定义的表计分组（如"1号楼"、"2号楼"、"商业区"等），支持父子层级。分组用于报表统计时的筛选维度和管理便利。

#### 操作步骤

**创建分组**
1. 点击「新建分组」按钮
2. 输入分组名称
3. 选择父分组（可选，不选则为顶级分组）
4. 选择关联商户
5. 保存

**编辑分组**
1. 点击分组旁的编辑图标
2. 修改名称或父分组
3. 保存

**删除分组**
1. 点击分组旁的删除图标
2. 确认后逻辑删除

**分组树展示**
1. 分组列表支持树形结构展示，可展开/折叠层级

#### API 接口

| 树形结构 | GET | `/api/v1/meter-groups/tree` | 分组树（含父子层级） |
| 创建 | POST | `/api/v1/meter-groups` | 新建分组 |
| 更新 | PUT | `/api/v1/meter-groups/{id}` | 编辑分组 |
| 删除 | DELETE | `/api/v1/meter-groups/{id}` | 逻辑删除 |

## 7. 客服收费 — 人工缴费

**菜单位置**: 客户收费 → 人工缴费

余额退补模块用于对商户账户余额进行调整（增加或扣减），串联「调整电价 → 选择表计 → 预览 → 执行」全流程。

#### 操作步骤

### 15.2 新建余额退补

1. 点击「新建余额退补」

## 18. 登录与认证

### 功能说明

小程序支持两种登录方式：微信登录和手机号登录。新用户首次登录后需绑定商户账户。

### 操作步骤

#### 微信登录
1. 打开小程序，点击「微信一键登录」
2. 授权获取微信头像和昵称
3. 系统调用 `wx.login()` 获取 code
4. 后端通过微信接口换取 openid
5. 若用户已绑定商户 → 直接登录成功，返回 token
6. 若用户未绑定商户 → 提示「请先绑定商户账户」，进入绑定流程

#### 绑定商户
1. 输入手机号
2. 点击「获取验证码」
3. 输入短信验证码
4. 系统验证手机号关联的商户信息
5. 绑定成功 → 自动登录

#### 手机号登录
1. 输入手机号和短信验证码
2. 系统自动匹配/注册并绑定商户
3. 登录成功

#### 获取当前用户信息
- 登录后自动显示：头像、昵称、关联商户名、绑定表计列表、账户余额

#### API 接口

| 接口 | 方法 | 路径 | 说明 |
| --- | --- | --- | --- |
| 微信登录 | POST | `/api/v1/miniapp/auth/wechat-login` | 微信 code 登录 |
| 绑定商户 | POST | `/api/v1/miniapp/auth/bind-customer` | 手机号+验证码绑定 |
| 手机号登录 | POST | `/api/v1/miniapp/auth/phone-login` | 手机号+验证码登录 |
| 用户信息 | GET | `/api/v1/miniapp/auth/me` | 当前用户信息 |

## 21. 扫码绑定表计

### 功能说明

商户通过微信小程序扫描表计上的二维码，将未绑定的电表/水表自动关联到自己的商户账户下。

### 操作步骤

1. 点击小程序中的「扫码绑定」功能
2. 扫描表计上的二维码
3. 系统自动判断：
   - 表计已绑定到当前商户 → 直接返回表计详情（幂等）
   - 表计未绑定（customer_id 为空）→ 自动绑定到当前商户
   - 表计已绑定到其他商户 → 返回错误提示，不可抢绑
4. 绑定成功后跳转到表计详情页

#### 二维码格式
- 新格式：`METER:<type>:<dbNo>`（如 `METER:1:DB0000000001`）
- 兼容旧格式：直接使用表号（系统优先匹配电表，其次水表）

#### API 接口

| --- | --- | --- | --- |
